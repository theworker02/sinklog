# sinklog

Sink numeric log values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/sinklog/

## Install / run

```bash
git clone https://github.com/theworker02/sinklog.git
cd sinklog
node src/cli.js
node --test
```
